# 🎰 Lucky7 — Table Management POS

A Point of Sale system with advanced table management, including **customer-split table mode**.

## Features

- **Table Management** — visual table layout and status tracking
- **Customer-Split Mode** — split a table between multiple customers with separate bills
- **Order Management** — add, edit, and close orders per table
- **Backend API** — Laravel REST API with full POS support

## Tech Stack

- **Backend:** Laravel (PHP), MySQL
- **Frontend:** React, Tailwind CSS

## Setup

```bash
composer install && php artisan migrate
npm install && npm start
```
